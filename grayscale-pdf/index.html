Frequently Asked Questions

How to convert PDF to black and white to save ink?

Upload your colour PDF to LovePDFs Grayscale tool and click Convert. The result uses only black ink when printed, saving significant ink costs.

How to print a PDF in black and white?

Convert your PDF to grayscale first using this tool, then print normally. Alternatively, set your printer to Grayscale mode in print settings.

Does converting to grayscale reduce PDF file size?

Yes — removing colour data from images and vector graphics typically reduces PDF file size by 20-40%.
